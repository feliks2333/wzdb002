个人档案 / PROFILE

STATUS:OPEN

我是谁

我是 WEIZHI，做影像、声音和交互装置的实验创作。习惯把过程也当成作品的一部分： 测试片段、失败样本、参数记录都会留档，而不是只留最终成品。

在做什么

目前重点在两件事：一是把声音的物理性（低频、震动、机械噪音）翻译成画面； 二是给声音做可交互的容器——装置、终端界面，或者一个能在展场自己跑起来的循环影像。

工作方式

  • 先做样本，再谈方案：任何想法先做成 30 秒能看/能听的东西。
  • 保持本地优先：素材、工程、成品都在自己的硬盘上，不依赖在线平台。
  • 保留可读的记录：每个项目都写清参数、工具与踩过的坑。

工具

Ableton Live、Max/MSP、After Effects、Premiere、TouchDesigner、Figma， 以及一堆自己写的小脚本（其中就包括这个站点）。

关于这个站点

站点用纯 HTML / CSS / 原生 JS 写成，工业机能风的界面：细边框、切角模块、等宽字体读数。 所有媒体路径集中在 assets/js/works.js，文件分别放在 media/music/、media/video/、 media/cover/。
